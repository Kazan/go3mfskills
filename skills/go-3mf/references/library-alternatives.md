# Library alternatives

Facts were checked on GitHub during this analysis. Re-check them before
you adopt a library.

| Option | License | Approach | Strengths | Risks for this use case |
|---|---|---|---|---|
| **Standard library** (`archive/zip`, `encoding/xml`) — these examples | BSD-3 (Go) | Streaming decoder with byte-span splicing | No dependencies; full control of preservation; `float64`; bit-identical untouched entries via `zip.Writer.Copy` | You own conformance; extensions beyond Core and Production are only preserved, not modelled |
| [github.com/hpinc/go3mf](https://github.com/hpinc/go3mf) | BSD-2-Clause | Typed model plus extension packages (materials, production, beam lattice, slice, …); decoder and encoder; validation | Broad spec coverage; spec-aware validation | Last push 2023-10; `float32` vertices (lossy for `float64` sources); full re-serialization changes bytes; preservation of **unprefixed** Bambu `paint_*` attributes unverified |
| [github.com/qmuntal/opc](https://github.com/qmuntal/opc) | BSD-2-Clause | OPC reader and writer (used by go3mf) | Correct OPC semantics: content types, rels, part names | Container only; you still need model parsing |
| [3MFConsortium/lib3mf](https://github.com/3MFConsortium/lib3mf) Go bindings | BSD-2-Clause | cgo over the reference C++ library (`Autogenerated/Bindings/Go`) | Reference implementation; maintained; all extensions; signing and encryption | cgo and a shared library to ship; needs a C++ toolchain; its writer regenerates the model, so Bambu-specific content is at risk |

## Choosing

- **Preserve slicer projects byte-for-byte:** use the standard library
  with splicing (these examples).
- **Read or produce many extensions (materials, beam lattice, slices):**
  use go3mf, after checking float precision and unknown-attribute
  round-trips on real Bambu files.
- **Need certified conformance, signatures or encryption, and cgo is
  acceptable:** use lib3mf.
- **Hybrid:** use go3mf or lib3mf for reading and analysis, and splicing
  for the write-back.

## Validators

- The authority is lib3mf (the 3MF Consortium's reference implementation)
  and the Consortium's published sample and test suites.
  `Document.Validate` here is a conformance aid.
- Testing Bambu compatibility needs real Bambu Studio projects. This
  bundle had none, so its Bambu claims come from reading `bbs_3mf.cpp`.
